Balik-Wika: An Interactive Web Platform with Machine Learning to Assess and Improve Filipino Language Skills and Cultural Awareness Among the Youth of Hilltop, Bagong Ilog Community

**Capstone Project | BS Information Technology**

## 📌 Project Overview
Balik-Wika is an interactive web platform integrated with Machine Learning designed to enhance Filipino language proficiency and cultural awareness. Developed specifically for the youth of the Hilltop, Bagong Ilog Community, the system addresses the declining use of the native language by providing a technology-based, culturally relevant learning tool.

## 🚀 Key Features
* **Adaptive Learning:** Uses a Machine Learning model to classify learners into Beginner, Intermediate, or Advanced levels based on performance.
* **Interactive Lessons:** Engaging modules and quizzes designed for young learners (ages 7-9).
* **Cultural Integration:** Lessons focused on Filipino cultural awareness and language preservation.
* **Progress Tracking:** Real-time monitoring of learner advancement and proficiency levels.
